About this project

A full relational design for a library system, built from a plain-language brief through to a working SQL Server database.

The problem

A library needed to track employees across floors, users and their borrowing history, and books connected to authors, publishers, categories and physical shelf locations — with several many-to-many relationships (books have multiple authors; users borrow many books).

What the schema covers

  • 9 core tables, normalized to 3NF, including a self-referencing Employee→Supervisor relationship
  • An associative "Borrow" entity resolving the User↔Book↔Employee relationship with its own attributes
  • Views with WITH CHECK OPTION to enforce business rules at the data layer
  • Triggers for audit logging and for blocking disallowed inserts/updates/deletes
  • Stored procedures and scalar/table-valued functions for reporting
  • Row-level security via a restricted SQL login (SELECT + INSERT only, DENY on UPDATE/DELETE)

This demo
